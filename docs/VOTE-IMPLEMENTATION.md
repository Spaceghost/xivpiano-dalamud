# Accepted vote implementation evidence

The full scope is the 18 accepted XivPiano ideas in ../ghostty-vote/data/catalogues/xivpiano.json, within the 201-vote cross-mod commitment. This document records evidence and does not certify the remaining ideas.

## piano-share-song — Share What’s Playing

Implemented the Now Playing Copy icon. It copies title/artist and an admitted public HTTPS pandora.com or www.pandora.com path to the clipboard. No stream URL, account token, query, fragment, userinfo or nondefault port is shared. Text controls and format characters collapse to spaces, Unicode scalars remain intact, title/artist have byte bounds, and the line stays within480 UTF-8 bytes. An unavailable or oversized link leaves song text only. The tooltip asks the user to choose their chat channel before pasting. It neither opens nor sends game chat.

## piano-song-events — Other Plugins Hear the Song Change

Added the XivPiano.SongChanged string message gate alongside existing polling/control gates. ## piano-duck-dialogue — Quieter While Someone Speaks

Opt-in DuckDialogue, default off, listens to Talk PostSetup/PreFinalize and unregisters on unload. DuckTo defaults0.25 and is configurable0..1. Framework updates apply a monotonic-time attenuation ramp separately from the user's saved Volume. The slider updates the base volume only, avoiding competing direct writes. Disabling ducking restores the current base level rather than a stale pre-dialogue value. Configuration rejects nonfinite gains; policy clamps invalid timing and values. Silence/voiced dialogue are treated alike; battle talk/other quest windows are not covered by the catalogue's Talk-first design. The lifecycle flag is reconciled with current Talk readiness/visibility on each enabled framework update, covering an already-open window after reload and a hidden-but-allocated window. No addon pointer is cached; disabled/area-transition frames avoid addon reads and clear dialogue attenuation intent.
